Account & Data Deletion

Zombie Wars · 5th Table

Before you delete

Deleting your account permanently removes everything tied to it:

  • Your player profile and display name
  • All progress — unlocked maps, vehicles, weapons and upgrades
  • All in-game currency and unclaimed mail rewards
  • Your leaderboard entries

Deletion cannot be undone. Anything you purchased is removed with the account and cannot be restored afterwards, so use any remaining currency first.

The fastest way is inside the game — it takes effect immediately:

Profile → Edit profile → Delete account

If you can no longer open the game on your device, you can request deletion right here. You will need your Player ID and an email address we can send a verification code to.

Deletion request

In the game: Profile → Edit profile — the Player ID is shown below the Delete account button; tap it once to copy. If you saved it earlier (a support email, a screenshot), paste it here.

We send a 6-digit verification code here. This address is only used for this request.

No Player ID and the game no longer opens? Email privacy@5thtable.com with your display name and anything that helps us find the account, and we will handle it manually.

Enter the code

We emailed a 6-digit code to your address. It expires in 15 minutes.

Entering the code confirms the request. The account is then deleted automatically after a 7-day cancellation window — opening the game on the account during that window lets you cancel, and you can also cancel on this page right after confirming.
